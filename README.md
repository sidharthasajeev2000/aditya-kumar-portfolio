# Aditya Kumar — Portfolio

Photographer & videographer portfolio, pitched for bike showroom brands.

- Instagram: https://www.instagram.com/stories.by.adithyakumar/

## Local

```bash
npm install
npm run dev
```

## Deploy

Static export to GitHub Pages (`basePath`: `/aditya-kumar-portfolio`). Set Pages source to **GitHub Actions**.

Live (after Pages is enabled): https://sidharthasajeev2000.github.io/aditya-kumar-portfolio/
